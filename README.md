# Michael Heavener

Bookkeeper and administrative assistant based in Sacramento, California, with 6+ years in bookkeeping, payroll, and customer operations.

I build MUSE, an agentic music-production system in Python, and small, sharp tools for my Omarchy/Hyprland setup.

## Selected projects

- [netwatch](https://github.com/michaelheavener4/netwatch) — Defensive Linux network-observation CLI: a read-only, /proc-based socket observer in Python, using only the standard library.
- [play-split](https://github.com/michaelheavener4/play-split) — Plays a YouTube/media URL in a tiled mpv pane on Omarchy / Hyprland.
- [mission-control-swipe](https://github.com/michaelheavener4/mission-control-swipe) — Swipe to dismiss windows in a custom Mission Control overlay for macOS (Hammerspoon).

My work here is mainly in Python, Shell, and Lua.
